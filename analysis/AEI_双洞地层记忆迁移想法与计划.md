# 里程寻址的地层记忆迁移：让先行洞告诉后行洞“前方是什么”

日期：2026-10-29。状态：想法与实施计划，**尚未实现，没有本方法的实验结果**。文中的数字来自仓库既有产出（P0–P3、最小验证实验）或对这些产出的只读核对，不是本方法的性能。不宣称首次提出；文献部分是快速定向检索，不是全文级查新。

本文引用的数据产出和两份 AEI 设计文档（[研究设计][ev-design]、[算法规格][ev-algo]）位于分支 `claude/bold-turing-u1beur`（提交 [`e73bd56`][ev-commit]），尚未并入本分支，文中链接固定到该提交。

## 摘要

- **想法**：迁移“地层记忆”，而不是模型。先行洞沿里程记录“比本机常态更难切多少”（机器归一化的响应指数），按里程存档；后行洞到达相应里程时调档，作为预测器的附加输入。算法规格中的推进量时钟 s 在这里既是时钟，也是地址。
- **立足点（只读核对）**：TBM5/6、TBM9/10 分别是同一工点的右/左线，同向推进，先后到达同一里程相差数天到数周。孪生机的因果对照中，60 秒扭矩只用孪生机训练，相对持久性 TBM10 为 +10.8%、TBM9 为 +9.9%；混合其余源机分别为 +7.0% 和 −0.7%。
- **最快证伪**：数据恢复后，对 TBM9 与 TBM10 在里程格上的地层指数计算偏移 δ∈[−100, 100] m 的相关曲线；峰值不在 δ≈0 附近，或不显著高于远偏移，想法作废。
- **主要风险**：只有两对双洞；里程计数器分辨率与质量；后行洞的地层已被先行洞扰动；60 秒点预测上的增益可能很小；只服务有邻洞先行的情景。

## 1. 想法

**1.1 一句话。** 迁移的对象不是模型权重或特征分布，而是“地层记忆”：先行洞沿里程记录的、已扣除本机常态响应的“难切程度”，按里程存档；后行洞到达相应里程时调档，作为预测器的附加输入。

**1.2 直觉。** 两条洞并排推进。先行洞通过里程 x 时，会在那里遇到比本机平常更硬或更软的地层，这个“比平常难切多少”按里程存入档案。后行洞走到 x 附近时调档（“这里上次通过时比平常难切 20%”）。两台机器穿过的是同一块地层，是天然的配对观测，有机会把“地层”与“机器”分开。算法规格中的推进量时钟 s 在这里兼作地址：s 不只是驱动状态演化的时钟，也是进入地层档案的索引。

**1.3 与已有工作的区别（待查新）。**

- 研究设计所列 Li 等（[E1]）以机械/经验关系变换源数据后微调；Wang 等（[E2]）用 KL 散度判据与 KL 正则微调。二者迁移的是模型或分布。
- 本方案迁移的是沿里程组织的、机器归一化的响应记录。快速检索没有发现“先行洞按里程存档、后行洞调档”的工作；最接近的是整条隧道级的跨洞模型迁移（[E6]）、同一条隧道内以历史掘进循环更新的高斯过程方法（[E7]）和用自身运行数据预测前方地层的工作（[E8]）。这不等于没有，不能据此宣称首创。

**1.4 适用范围与边界。**

- 档案只在存在邻洞、且邻洞记录先于本机到达时非空。对全新工点的新机器档案为空，应使用 §7 中的其他方案。
- 不输出司机操作设定值；指数是机器归一化的响应，不是岩性或岩体参数，不做地质解释。
- 后行洞遇到的地层可能已被先行洞扰动；档案传递的是“先行洞当时的响应”，不是后行洞地层的真值。

## 3. 方法规格（候选）

**3.1 机器归一化的地层指数。** 对机器 k，取 `valid_core` 且 `active` 的行（排除 `q_*` 硬标志行）。用该机器源训练期的数据拟合“常态响应”，只拟合一次并冻结：

```
log T ≈ f_T,k(log n, log v)        log F ≈ f_F,k(log n, log v)
r_T(t) = log T(t) − f_T,k(log n(t), log v(t))        r_F(t) 同理
```

r>0 表示在当前工作点上比该机器的常态更难切。f 先取对数线性模型，复杂度只在源验证上选。这类似贯入指数（T/p、F/p），区别是按机器自己的常态归一。F、T 的单位仍未核实（[`field_dictionary.csv`][ev-fields] 的 `unit_status`），取对数后指数不依赖单位的乘性尺度。

**3.2 里程档案。** 以里程格为键。格宽从 max(计数器步长, 2 m) 起步；TBM9/10 在位置重建验证之前先用 5 m。每格保存 r_T、r_F 的中位数和离散度（MAD）、有效行数、数据日期范围、来源机器与文件编号、被质量标志排除的行比例。每条记录带“记录时间”，调档时只可读取记录时间早于决策时刻的条目。

**3.3 对齐与换算。** 对后行洞 M 与先行洞 L：

```
r_M(x) ≈ a · r_L(x + δ) + b,        δ ∈ [−100, +100] m,   a > 0
```

δ 吸收里程参照差与洞间错位（两洞相距几十米，斜交结构会错位）；a、b 吸收两台机器“难切程度”的尺度和偏置差。三个参数只用 M 已走过且 L 也走过的路段估计（滚动窗口，长度在源期选，鲁棒损失）。可靠度 ρ 为该滚动窗口内 r_M 与换算后档案预测的相关系数。

**3.4 调档特征。** M 在里程 x 时：档案在 x+δ 处的换算值；前方 5/20/50 m 的均值、最大值和梯度；格内离散度和行数；档案年龄（先行洞通过该里程至今的天数）；ρ；可用标志。

**3.5 预测任务与预测器。**

- (a) **主终点**：60 秒扭矩，沿用研究设计的逐机 MAE 与相对持久性的 skill，便于对照。
- (b) **距离型**：前方 d ∈ {5, 20, 50} m 的平均 r_T 与 r_F。60 秒内机器只前进几厘米，档案的价值预期主要体现在较长的前瞻和启停过渡期，所以必须单独评价。标签在 M 走到 x+d 时成熟。
- (c) **事件型**：硬地层起点，即 r_T 持续高于该机器训练期某高分位的路段起点；评价预警提前量与误报。分位与持续长度在协议文件中冻结。

预测器沿用仓库当前最强的简单基线（HistGB，L1 损失，4 次滞后及时间间隔特征），档案特征作为附加列，不引入新网络；缺失由树模型原生处理。

**3.6 兜底与防泄漏。**

- ρ 低于源期选定的阈值，或先行洞在该里程无记录，档案特征置缺失。
- 档案只含决策时刻之前已记录的先行洞数据；f_k、δ、a、b 和阈值只用决策时刻之前的数据或源期数据。
- 建档用的分段/阶段标签（P2）只对先行洞已完成部分计算，不得读到决策时刻之后的数据。
- 主终点、阈值、分割、对照和停止规则在运行 G3 之前写入协议文件并提交。
- “先行”按里程判定：该里程上较早到达者。TBM9/10 的先后会轮换，同一台机器在不同路段既可能有档案也可能没有。
- 沿用研究设计的其他边界：全运行视图为主评估，P2 阶段只作事后分层，不使用目标未成熟标签。

## 4. 验证设计与证伪

**4.1 核心证伪（G1）。** 先不训练任何预测模型，只检验“两洞在同一里程上的地层指数是否相关”：

- 数据：TBM9、TBM10 的共同覆盖路段（约 3.7 km）；TBM5、TBM6 的重叠路段（约 0.6 km）作较小的重复检验。
- 指数：§3.1，里程格内取中位数；每格有效行数门槛在看到相关结果之前按行数分布冻结。
- 去趋势：各洞减去 200 m 滚动中位数，去除缓变的共同趋势（刀具磨损、机器漂移）。
- 统计量：Spearman 相关 ρ(δ)，δ ∈ [−100, 100] m，步长 5 m；零分布取 |δ| ≥ 200 m 的相关；按连续 100 m 块做 bootstrap 区间。
- 暂定通过标准（看结果前冻结，可在 G0 之后修订）：峰值位置 |δ\*| ≤ 50 m；ρ(δ\*) ≥ 0.4；高于零分布的 95% 分位；TBM9 跟随 TBM10 与 TBM10 跟随 TBM9 两个方向各自成立；TBM6 跟随 TBM5 的方向一致。
- 不通过：终止，不进入 G2，按阴性发现归档。

**4.2 对照、消融与安慰剂。**

| 对照 | 目的 |
| --- | --- |
| 持久性 | 下限 |
| 自身历史 GBDT（4 次滞后，仓库现有最强简单基线） | 档案是否提供自身历史之外的信息 |
| 自身历史 + 分钟级滚动统计特征的 GBDT | 排除“只是更长的记忆” |
| 只用孪生机训练的模型（§2.3） | 里程寻址是否优于模型级孪生迁移 |
| 档案，固定 δ=0 / 不做换算（a=1, b=0）/ 不用可靠度 | 逐项消融 |
| 档案平移 ≥200 m；跨工点的档案；时间打乱的档案 | 安慰剂：增益必须消失，否则不是来自共享地层 |
| TBM8（无邻洞）、各机器无档案的路段 | 阴性对照：无档案则无增益 |

**4.3 评价协议与指标。**

- **分割。** 既有“每机时间 60/20/20”不适用。TBM9 的测试期（2024-06-13 起）恰好处于它领先的路段，没有档案；TBM9 作为后行洞的路段（约 1,013,647–1,015,947 m）绝大部分落在它的训练期内。需要按“有档案的路段”设计滚动起点分割：训练只用早于预测时刻的数据，每个有档案的路段内按时间顺序留出后段作测试；另做跨对泛化（在一对双洞上学档案特征的用法，在另一对上测试）。细节在协议文件中冻结。
- **主终点。** 后行洞窗口上 60 秒扭矩的逐机 MAE 与相对持久性的 skill，日块 bootstrap 区间；与“自身历史 GBDT”配对比较。
- **过渡与持续运行。** 停机后重启的前若干分钟与持续运行窗口分开报告（事后分层，不进特征）。
- **距离型。** 平均 r 的 MAE，及相对持久性（最近 5 m 均值）和自身历史 GBDT 的 skill。
- **事件型。** 召回、误报、预警提前量。
- **逐对逐方向报告。** 附独立日块数与里程格数，不把不同对的结果合并成一个宏平均而不展示分项。另报告档案覆盖率与年龄分布。

**4.4 判定与收缩规则。**

1. G1 不通过：终止。
2. G1 通过，但 G3 中档案特征相对“自身历史 + 分钟级滚动特征”的逐机增益区间含 0：缩减为“发现 + 评估协议”。
3. 安慰剂（平移 ≥200 m、跨工点档案、时间打乱）后增益未消失：增益不是来自共享地层，不得写作地层迁移。
4. 增益只出现在一对双洞、一个方向或一个时间段：不写作普遍有效。
5. 档案在距离型/事件型任务上有增益、但 60 秒点预测上没有：如实报告，贡献限定在前瞻任务。

## 6. 风险与不能声称的内容

**风险**

- 只有两对双洞，TBM5/6 的重叠路段仅约 0.6 km，TBM6 的 2024 年数据是 TBM5 的副本；结论只能写作两个工点的案例研究。
- 里程计数器：步长 1 m、跳变与零值、TBM10 净推进偏低；档案的空间分辨率可能只能到 5 m 量级。
- 记录不连续：档案在缺口路段为空。
- 后行洞的地层已被先行洞扰动；洞间距和斜交结构可能使局部响应对不上（G1 检验）。
- 地层之外的运行因素（设备、检修、运行策略）可能主导推进速率；指数虽扣除机器常态，仍可能残留运行效应。
- 60 秒点预测上的增益可能很小，价值可能只在前瞻与过渡期。
- 现有评估的功效有限：宏平均区间半宽约 4 个点（[验证报告][ev-report] §三，60 秒扭矩，学习模型减简单方法为 +2.3% [−2.7%, +5.2%]）。
- 只服务有邻洞先行的情景。

**不能声称**

- 识别了岩性、岩体参数或地质界线。
- 提升进尺、减少卡机或换刀、提高安全。
- 对新工点或新机型普遍有效。
- G1 的相关性等于因果。
- 首次提出该方法。
- 60 秒扭矩之外的任何结论（均属探索性）。

## 7. 与其他方案的关系

| 场景 | 方案 | 状态 |
| --- | --- | --- |
| 有邻洞先行 | 本方案 | 待 G1 |
| 全新工点的新机器、少数据 | PC-OKT（[算法规格][ev-algo]）；或“关系感知、风险受控的来源选择规则”：在源机之间做迁移演练并记下实际增益，在线按最坏情况增益决定用谁，否则退回持久性 | PC-OKT 待实现；选择规则只是设计草案 |
| 启停与换环 | 行程相位（备选 1） | 数据中有结构证据，未检验 |
| TBM8/9/10 | 设定值条件化（备选 2） | 未检验 |

与 PC-OKT 的衔接：推进量时钟可直接用里程计数器差分（注意 NaN、`q_counter_glitch`、TBM6/TBM9/TBM10 的计数器分辨率），本方案的档案特征可作为 PC-OKT 状态更新的外部输入，或后行洞预测器的候选底座。

**备选 1：行程相位。** [`segments.csv`][ev-seg] 中，TBM8/9/10 的长且两端均未被截断的掘进段，推进量（速度积分）无一超过 2.0 m，并在 1.6–2.0 m 堆积：TBM8 约 35%、TBM9 约 22%、TBM10 约 13%（样本数 434、2,774、2,236）；TBM5 约 7%，且有少量 2.0–2.4 m（样本数 1,699）。这提示掘进受行程限制，启停和换环可由“行程相位”预测，而基线的 4 次滞后特征没有这一信息。停机窗口承担的 60 秒持久性误差：扭矩 15.7%–25.5%，推力 42.8%–71.6%（[`C_strata.csv`][ev-C]），这只是行程相位预测的上限量级，不是承诺。

**备选 2：设定值条件化。** TBM8/9/10 的所有文件都有刀盘给定转速和推进给定速度列，TBM9/10 另有推进压力设定，TBM8 没有；TBM5/6 最常用的 275 列模式中没有任何给定/设定/设置列，上述三类设定值通道在它们所有文件中的覆盖率为 0%（[`schemas.json`][ev-schemas]、[`file_audit.csv`][ev-audit]）。转速设定与实测转速之比的中位数为 0.988–0.991（P0 `ratio_n_over_n_set`），转速设定近乎冗余，增量只可能来自推进速度和推进压力设定。standard_v1 的 39 个字段不含设定值，需要从原始数据补进 P1。文献线索见 [E4]（检索转述，未读全文）。检验：看条件于设定值能否缩小“零样本—同机”的差距。

**8.3 核对方法**（可由上述文件复现）

1. **里程轨迹与先后到达。** 取 `file_provenance.csv` 中每个文件的首末里程值（TBM5/6 用 `刀盘里程_first/last` 取绝对值并限定 734,000–737,000 m；TBM9/10 用 `导向盾首里程_first/last` 并限定 1,010,000–1,020,000 m；`valid_share≥0.3`；排除 `trusted_sources.csv` 中状态为 exclude 的文件），配合 `time_min/time_max` 得到（时间，里程）点；按推进方向取单调包络，线性插值得到每 100 m 里程的首次到达时间，再求两洞之差。时间分辨率受文件跨度限制（通常按天）。
2. **60 秒扭矩表。** `D_metrics.csv` 取 `split=test, model=HistGB_L1_delta, target=T, train_n=24000, clean_train=False, horizon_s=60`，各 variant 的两个种子取均值。变体对应：同机 = `within`；只用孪生机 = `lomo_same_sampling`（TBM9/10，源仅为对方）或 `lomo_time_causal`（TBM5/6，因果下仅剩对方）；混合 = `lomo_time_causal`（TBM9/10）；去掉伙伴 = `lomo_no_overlap_partner`。训练集构成与因果标志见 `D_training_sets.csv` 的 `sources`、`all_train_before_target_cutoff`。
3. **设定值覆盖。** `file_audit.csv` 的文件到模式编号，`schemas.json` 的模式列名，`trusted_sources.csv` 的文件到数据流/机器；列名匹配“刀盘给定转速|刀盘速度设置”“推进给定速度|推进速度设置”“推进压力设定”。
4. **行程上限。** `segments.csv` 中 `seg_class=long` 且两端均未被截断的段，推进量取 `adv_v_m`。
5. **停机误差占比。** `C_strata.csv` 中 `model=Persistence, state=stopped_at_target` 的 `share_of_model_error`，60 秒。
6. **里程质量。** `trusted_sources.csv` 的 `chk_closure` 按机器计数；`file_provenance.csv` 的 `adv_v_m` 与 `adv_cutter_net_m`（TBM5/6）或 `adv_chainage_net_m`（TBM8/9/10）按机器求和后取比值；`advance_check.csv`。
7. **外部文献。** 网页检索结果摘要，未读全文；编号对应 §8.1。
