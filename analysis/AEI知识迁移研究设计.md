# 面向Advanced Engineering Informatics的TBM知识迁移研究设计

日期：2026-10-29。目标期刊：Advanced Engineering Informatics（AEI）。这是研究定位与待执行方案，尚未取得下述方法的新实验结果，不是已完成论文或投稿材料。

算法深化版本见[TBM动态算子知识迁移候选算法](AEI_TBM动态算子迁移算法.md)：以历史时间、转动与推进进程驱动共享动态算子，结合有限前缀校准。本文中的局部稳健回归保留为最小原型与强基线；动态算子版本的性能和新颖性均待验证。

## 1. 研究定位

**工程任务：新TBM或运行工况变化后，以有限历史观测建立可追溯的载荷预测模型，降低重新标定所需的数据量，并识别不适用的历史知识。**

主要用户是建设单位或承包方的设备监测、模型维护人员。系统的决策对象是“采用哪份历史知识、如何校准、何时暂停复用”，当前不输出司机操作设定值，不承诺提高日进尺、减少卡机或减少换刀。

核心研究问题：能否将历史TBM运行响应形式化为带适用条件、预测关系、不确定性和来源证据的知识单元，在新设备有限历史下完成可审计的知识选择与校准，比直接共享模型、普通微调或目标机独立建模更省数据、更少出现迁移退化？

暂定标题：

**Provenance-Aware Transfer of Operational Response Knowledge for Data-Efficient TBM Load Forecasting**

中文：**面向少数据载荷预测的TBM运行响应知识表征与溯源迁移**。

“更省数据”“更少退化”均为待验证假设；若实验不成立，标题及贡献必须相应收缩。

## 2. 与AEI的匹配依据与已有研究

Elsevier官方期刊说明强调知识和工程应用，通常不接受缺少知识显式表示和使用、仅应用软计算或模式识别的研究；将成熟方法用于新领域需展示新的能力、通用性或可扩展性。[AEI官方范围](https://shop.elsevier.com/journals/advanced-engineering-informatics/1474-0346)

这意味着论文必须展示“何种知识被形式化，表示怎样参与计算，怎样验证支持工程任务”，不能仅把模型参数或任意隐向量改称知识。无需为了期刊定位强行加入知识图谱；若结构化知识对象已足以支持推理和审计，就用可计算的对象与关系实现。

## 3. 明确知识对象，而不仅是迁移模型权重

定义每个知识单元为：

\[
\mathcal K_j=(C_j,R_j,U_j,P_j).
\]

| 部分 | 含义 | 现有数据中的可计算内容 |
| --- | --- | --- |
| 适用条件C | 该响应关系在哪些观测条件下获得、在哪里有支持 | 历史窗口的F/T/n/v支持范围、变化幅度、物理时间跨度和采样间隔、字段口径、修复状态 |
| 响应关系R | 由截至t的历史得到未来载荷响应分布的经验关系 | 指定时域的局部动态回归或概率预测器；小规模试验先用简单模型，避免网络容量混杂 |
| 可信度U | 关系在独立源验证数据上的误差、覆盖率及支持量 | 分块误差、区间宽度与覆盖、独立日期数、支持范围外标记；没有证据时标为未知 |
| 来源P | 关系从哪里来、经过哪些修复、由什么版本生成 | 机器及来源文件、原始行号/时间段、源训练时间上界、质量规则、单位状态、数据与代码版本 |

R是观测历史与未来响应的条件关系，不是改变推力/转速后的因果干预规律。C描述观测支持，不能自动解释为岩性或岩体参数。各单元不得跨入源验证/测试时间以增加支持量。

知识单元的形成应在源数据中完成：初版可按时间连续且质量合格的源片段建立候选局部模型，或只在源训练数据内形成有限个原型。候选单元数量、最小日期/数据支持量和构建方式只通过源验证选择。不能事后挑选目标测试期误差小的片段作为“可迁移知识”。

## 4. 知识迁移过程

1. **提取和登记。** 在源训练数据中形成知识单元，附上适用域、源验证结果和完整来源记录。
2. **匹配。** 对新机截至当前的前缀，计算其与C的重叠程度、动态相似性和采样跨度差异。源机器编号本身不是相似性的依据。
3. **有限校准。** 对有支持的响应关系做小参数量的偏置、尺度或残差校准；参数只用已到达且标签已成熟的目标观测估计。校准数据不足则跳过对应步骤。
4. **组合或拒绝。** 使用源内验证预定的规则及目标历史的顺序误差选择/组合知识。当历史支持不足或已观测误差超标时，回退到持久性或允许数据量下的本地模型。不得使用未来测试误差决定何时拒绝。
5. **输出可核查依据。** 给出预测、区间、来源单元、适用条件覆盖、校准数据量和拒绝原因。解释来自实际参与计算的对象和规则，不由语言模型事后编造。

工程原型可以是一份机器可读的知识库加一页回放面板；当前阶段不建设完整控制系统。回放要能回答“这次预测复用了谁的哪段经验，是否超出历史支持，为什么接受或回退”。

## 5. 三项待验证的方法贡献

- **显式知识表征：** 来源、适用条件和可信度共同约束运行响应关系的复用。验证重点是删除这些部分后是否改变选择结果并损害任务表现，而不是仅展示一张结构图。
- **时间跨度感知的有限校准：** 在不同采样间隔下匹配物理时间范围及动态关系，检验是否优于直接按固定条数迁移。现有基线已经包含历史时间间隔，不能把“加一个dt特征”单独写作创新。
- **证据驱动的复用/拒绝：** 在目标历史有限时评估知识是否适用，比较与普通微调及简单误差门控的差别。只能声称实测降低负迁移，不预先保证从不退化。

这些均为候选贡献。只有通过强基线和消融后，才可以作为论文贡献陈述。

## 6. 数据与防泄漏边界

- 初始范围为P0—P3支持的TBM5、TBM6、TBM8、TBM9、TBM10；设备归属、单位按现有证据状态注明。采用暂归TBM5的2024流不等于已获得现场证明。
- 主预测输入为截至t的F、T、n、v及其时间信息。p和电机通道只在明确披露的数据修复协议中使用，保留修复来源。
- 主评估使用全运行视图中的有效活动起点，包含未来停机和变化。P2阶段、段是否够长、是否稳态等只作事后分层；不得用于主在线任务的特征或事前准入。
- 未来载荷标签到达之前不能用于适配或门控；每个决策记录可用数据截止时间。重复及来源混入的排除沿用可追溯清单。
- 转速修复分别比较：不依赖全期拟合的v/p路径、排除修复行的敏感性；电机比例系数限定在允许的源训练/目标前缀内估计。全期目标机统计量不能默默用于严格零样本实验。
- 源与目标时间的两种实验分开命名：离线留一机器检验跨机复用；日期因果回放只使用早于当前目标预测时间的源知识。某些早期目标没有足够源机时如实报告，不使用后来项目补足“历史部署”证据。
- 当前数据已经多轮探索，不能把新划分声称为从未观察的外部盲测；论文应披露探索与规则冻结时间。

## 7. 最小验证设计

主终点暂定：60秒扭矩预测的逐机MAE及相对持久性的skill。30/120秒及F、v为次要终点。最终规则在执行新实验前以单独协议文件锁定，不能看新测试结果后换主终点。

外层逐台留出目标机，知识表示和超参数在其余源机内选择。严格零样本不读取目标验证标签；有限历史适配与零样本分表报告。多个目标锚点按预先规则确定，锚点之后测试区间固定，所有数据预算用相同测试窗口比较，并排除时间边界未成熟的标签。

适配预算先检验5、15、30、60、120分钟有效活动观测曝光；同时报告日历等待时间、实际读数、独立掘进段/日期数量。曝光只根据当时已观测的活动与采样间隔累计，不能用P2未来定义的完整段筛选前缀。几分钟可能只有十几条读数，不能把滑动窗口数当独立样本数；不足拟合的方案必须回退或标记不可用。

| 对照 | 比较目的 |
| --- | --- |
| 持久性及源验证选定的简单平滑/校准 | 证明复杂复用确实有增量 |
| 只用同样目标前缀独立训练 | 判断源知识是否比同等数据量的本地学习更有价值 |
| 合并源机训练后直接使用 | 判断显式选择与知识结构的作用 |
| 合并源模型加偏置/尺度校准 | 排除收益仅来自简单量纲或偏置修正 |
| 普通微调/残差适配 | 与同等目标数据量的常见迁移方法公平比较 |
| 仅相似度检索，不使用来源和可信度 | 判断知识对象各部分是否有用 |
| 所提方法及删除C/U/P、时间跨度、校准、拒绝步骤的消融 | 逐项检验候选方法贡献 |

小样本下不能拟合的复杂模型不强行比较；训练样本、参数规模、调参预算和来源数据可用时间一并记录。已有知识驱动迁移方法在可获取实现及必要元数据时优先复现；若缺少设备几何等条件，说明无法公平复现的部分，不将简化版本冒称原方法。

指标包括逐机MAE/RMSE、适配曲线、负迁移发生率与退化幅度、拒绝/回退比例、迁移相对本地模型的增益、达到预设误差容限的数据需求、更新耗时。区间预测另报告覆盖和宽度；声明90%等覆盖目标前需明确对应分布、校准期和适用条件，不保证漂移下无条件覆盖。

采用配对时间块比较，检验日块与连续多日块长度敏感性；按机器等权报告，不把百万重叠窗口视为百万独立重复。次要终点的统计结论需处理多重比较或明确为探索性。工程误差容限若没有现场依据，只能称研究容限，不能称现场验收标准。

## 8. 推进与收缩规则

1. 先重建并验证P1—P3，处理自审报告中的在线边界和修复依赖，再冻结P4协议。
2. 先执行源知识直接复用、简单校准、目标独立训练三组对照，检验数据中是否有值得进一步提取的迁移收益。
3. 有依据后实现知识对象与选择、校准和拒绝模块；先检验相对强简单基线的增量，再扩展网络容量。
4. 若方法绝大多数时候回退持久性，或与简单校准相当，不能声称知识迁移成功；若改善仅在一台机器或单一时间段，不写作普遍跨机有效。
5. 若显式知识字段没有参与推理或消融无增益，不把“知识表征”作为主要贡献。若普通微调已解决问题且无额外方法价值，重新评估AEI定位。

## 9. 预期论文结构与结果边界

建议结构：工程知识复用任务与相关研究；知识对象及提取；有限历史下的适用性推理与迁移；时间与数据来源约束；多机回放、基线和消融；知识复用案例及失败案例；工程部署边界。

必须有的图表：知识单元实例及原始证据链接；跨机/跨时间实验示意；各数据预算的逐机误差曲线；负迁移幅度和回退率；来源/条件/可信度消融；接受与拒绝迁移各一个完整回放案例。

可争取的结论是“显式、可追溯的运行响应知识有助于有限数据下建立预测模型并控制迁移退化”。不能仅凭本数据宣称：已掌握岩体机理、提升真实施工进尺、节约人工工时、提高安全性或获得现场认可。

目标确定为AEI，但知识表示、方法增量及实验结果仍决定投稿竞争力；本方案不构成录用或分区承诺。
