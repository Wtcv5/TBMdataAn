# TBM监测过程驱动的动态算子知识迁移：候选算法规格

日期：2026-10-29。状态：待实现、待比较的新算法设计。目标为AEI研究设计中的方法核心，不宣称首次提出或已有性能增益。

## 一、主张与工程任务

从已观测的TBM监测序列学习可复用的动态演化算子，在新设备少量历史条件下，选择并校准算子知识，建立未来载荷预测。研究的工程对象是监测模型的建立、校准和可靠复用，不是设备控制指令。

暂定名称：**Process-Clock Operator Knowledge Transfer（PC-OKT）**，中文“进程时钟驱动的动态算子知识迁移”。名称仅用于组织实现，不代表已取得方法原创性。

与上一版局部回归方案的关系：局部稳健回归和仿射校准保留为强基线；本方案以可学习的监测状态演化作为候选核心，知识对象的条件、可信度与来源仍保留。

## 二、为什么需要TBM特定的结构

| 已知数据特点或建模条件 | 算法对应 | 必须避免的解释 |
| --- | --- | --- |
| 读数间隔为10/20/30秒等混合，历史跨度跨时期变化 | 每次状态更新直接使用真实时间间隔 | 记录条数等于固定物理时长 |
| 刀盘转动与向前推进可分开发生；空转、停转与推进的监测响应不同 | 引入历史转数和推进量的累计进程，分别驱动动态算子 | 转了相同圈数就必然遇到相同岩石或相同载荷 |
| 机器和工况之间存在尺度及响应差异 | 共享知识算子，小参数量观测校准与组合 | 仅靠四信号就能识别机器差异和地质差异各自的因果贡献 |
| 历史与未来启停可能不同，既有阶段标签使用未来信息 | 主预测采用全运行视图；门控只读历史 | 用P2事后阶段作为实时已知特征 |
| 新机历史少，完整网络微调可能不稳 | 冻结主要动态算子，只校准小模块 | 有少量窗口就足以稳定训练所有参数 |

F、T、n、v均为闭环运行的实测量。本算法不把F/n默认当成独立可控设定值，也不把v/T默认当成仅受它们驱动的结果。

## 三、历史进程的计算

输入观测为\(x_i=[F_i,T_i,n_i,v_i]\)，时间为\(t_i\)。对截至当前预测起点的相邻有效观测，计算：

\[
\Delta t_i=t_i-t_{i-1},\quad
\Delta r_i=\frac{n_i+n_{i-1}}{2}\frac{\Delta t_i}{60},\quad
\Delta s_i=\frac{v_i+v_{i-1}}{2}\frac{\Delta t_i}{60}.
\]

若n为rpm、v为mm/min，则r为转数、s为mm。单位依据沿用数据字典，并保留未获设备资料确认的状态。时间、r、s分别用源训练期固定尺度缩放，不用目标全期统计量。

这只是历史区间内的梯形积分近似，不生成新的传感器真值，不代表真实区间内运动完全已知。超过既定采样缺口、质量不合格或反转状态未明确的区间不积分并重置历史。s/r接近0时无需计算比值，避免低速除法失稳。n修复依赖及质量标记必须进入协议与敏感性分析。

这三个进程不是三个独立信息源：r和s由已有n/v及时间计算。算法优势若存在，应来自结构归纳偏置而不是信息量增加。主要收益必须与“把同样增量直接输入GRU/TCN”的对照比较。

## 四、知识单元：共享坐标下的动态算子

\[
\mathcal K_j=(A_j^{t},A_j^{r},A_j^{s},C_j,U_j,P_j).
\]

- \(A_j^t\)：历史经过时间相关的隐状态演化。
- \(A_j^r\)：历史刀盘转数相关的隐状态演化。
- \(A_j^s\)：历史推进量相关的隐状态演化。
- \(C_j\)：源训练数据中该单元有支持的历史信号及进程条件。
- \(U_j\)：源验证误差、区间表现、支持日期数及当前支持不足程度。
- \(P_j\)：源机器、时间、文件、修复、单位、数据和模型版本。

所有单元共用编码器E及状态坐标，避免将不同潜空间的矩阵直接加权。候选状态维度先取16或32，候选算子单元数先取2或4，均只在源机内选择，不预先解释为“某种岩性”或“某种磨损状态”。

## 五、核心状态更新

在当前预测起点之前的每个观测i，分别维护各单元的历史状态：

\[
z_{j,i}^{-}=
\exp\left(\delta_i^t A_j^t+\delta_i^r A_j^r+\delta_i^s A_j^s\right)z_{j,i-1},
\]

\[
e_{j,i}=E(x_i,q_i)-H z_{j,i}^{-},\qquad
z_{j,i}=z_{j,i}^{-}+G_\theta(z_{j,i}^{-},x_i,q_i,\delta_i)\odot e_{j,i}.
\]

其中\(\delta\)为缩放后的进程增量，q包含当时可获得的质量与观测缺口信息；H将隐状态投影到编码观测坐标，G输出0到1的观测更新门。零历史状态可由首个已观测值初始化。模型在监测读数到达时校正状态。

可选地将各算子参数化为\(A=S-S^\top-LL^\top-\epsilon I\)，使非负进程增量下的无输入连续演化具有耗散性。这个性质只约束齐次算子部分；不能据此保证带观测更新、门控及输出的完整模型稳定，更不能称物理守恒。

三个算子是可学习的经验状态演化结构，不是已知破岩方程。其参数不具有天然唯一的物理解释，需要通过干预式输入对照、消融和可重复预测结果评价。

## 六、预测与知识组合

每个单元在历史截止状态上直接输出指定未来时域的分布：

\[
p_j(y_{t+h}\mid x_{\leq t})=D_\theta(z_{j,t},x_t,h),\qquad y=[F,T,v].
\]

首版用直接多时域解码，不在未来步中使用真实r/s增量，因为未来n/v未知。若以后使用滚动解码，须联合预测未来n/v并传播其不确定性，另作比较，不能读取测试标签生成未来进程。

组合权重只由历史支持与已经成熟的误差决定：

\[
w_{j,t}\propto\exp\{-\alpha d(C_t,C_j)-\beta E^{past}_{j,t}-\gamma U_{j,t}\}.
\]

本地候选j=0包含持久性及允许数据量下的简单模型。源内验证选择门控规则；不得在目标未来误差出现后才决定刚才应选哪个专家。极少历史时无法可靠估计误差，应使用预定冷启动策略，不输出伪精确权重。

每次预测保存：来源单元、支持差异、已到达校准标签数、权重、回退原因。只有P用于源可用时间、质量和数据独立性等实际约束时，才可声称其参与了知识使用；仅显示文件名属于溯源功能，不是精度创新。

## 七、小样本适配与源内训练

初版冻结E、H、D及主要算子，目标机仅学习：输入的四通道仿射校准（向恒等映射收缩）、输出偏置、有限个知识权重参数。控制目标可训练参数量，精确报告数量。

主训练过程在外层留出目标机之外的源机中执行：

1. 只用源训练期形成C和知识库，训练状态更新与多时域预测。
2. 在源机内部模拟“前缀适配→后续预测”，学习或选择小样本校准的正则强度和门控超参数。每个模拟任务的标签成熟时间必须早于其后续预测时刻。
3. 每次外层目标机完全不参与超参数、单元数及训练轮数选择。有限目标前缀用于校准的结果与完全不校准的零样本结果分别报告。
4. 新机历史内的校准拟合与校准效果评估按顺序分开，或使用严格的先预测后更新，避免用拟合残差充当泛化可信度。

训练损失可从\(L_{forecast}+\lambda_{sam}L_{sampling}+\lambda_{adapt}L_{adapt}\)开始：

- 预测损失：与MAE终点一致的L1或分位数损失，不默认平方损失。
- 采样一致性：源训练历史做受控稀疏化，两条历史都截止同一t时，鼓励预测一致；仅对变化较缓、积分近似可信的配对使用。不得强迫删除峰值后仍恢复完全相同的信息。
- 适配正则：限制少量目标数据导致的尺度、偏置和权重极端变化。

这些损失项均须消融；若没有增量就删去，不预先堆叠多项损失并宣称创新。

## 八、决定方法是否成立的实验

| 对照/实验 | 回答的问题 |
| --- | --- |
| 同容量GRU/TCN，输入含dt、r/s增量 | 是否只是多加了几个特征，而不是动态更新结构有用 |
| ODE-RNN或Neural CDE，以及只含时间算子的模型 | 是否仅由通用不规则时间建模带来收益 |
| 三种算子去掉转动、推进或合并为一个算子 | TBM进程拆分是否必要 |
| 相同原始历史受控降采样，保持预测标签和截止时间不变 | 隔离观测采样变化；不能只比较不同地段就归因为采样 |
| 单源/合并源模型、同数据量目标独立训练、普通微调、小参数校准 | 知识迁移是否比常见做法更有价值 |
| 不使用适用域或不使用历史误差的均匀融合 | 选择依据是否真的改善迁移 |
| 保持额外特征不变、打乱r/s增量对应关系（仅诊断，不训练部署） | 是否学到与真实进程对齐的响应，而非仅利用额外自由度 |
| 全运行主评估，P2阶段只作事后分层 | 启停窗口是否使收益消失，防止事后筛简单样本 |
| 修复n与排除修复行的敏感性 | r进程收益是否依赖修复/派生关系 |

指标、适配预算、外层留机、日期因果与离线跨机区分、置信区间和停止规则沿用AEI主设计。主终点暂定60秒扭矩，次要F/v与30/120秒不能事后替换主终点。五台机器结果逐台披露，不能仅报告总体平均。

候选贡献的可证伪表述：**如果同容量dt-GRU或通用连续时间模型已取得相同效果，则TBM进程算子结构没有得到支持；如果只做输出偏置校准就达到同样收益，则复杂知识迁移没有得到支持。**

## 九、与已有算法的关系和新颖性状态

Neural CDE与ODE-RNN已处理不规则时间序列，不能将连续时间建模、潜状态、稀疏观测或加入dt本身称为新贡献。[Neural CDE，NeurIPS 2020](https://papers.nips.cc/paper/2020/hash/4a5876b450b45371f6cfe5047ac8cd45-Abstract.html)；[Latent ODE/ODE-RNN，NeurIPS 2019](https://proceedings.neurips.cc/paper/8773-latent-ordinary-differential-equations-for-irregularly-sampled-time-series.pdf)。

候选方法的区别是：以TBM历史经过时间、转动和推进三种进程约束状态演化；将共享坐标下的算子及其适用条件和证据作为知识对象；在新机前缀内进行小参数量校准及复用选择。是否有足够新意，仍须完成更全面的算子迁移、混合专家、过程驱动系统辨识等全文查新与对照。

当前没有可报告的PC-OKT实验结果。下一步是建立严格原型并完成最小消融，而不是立即将本规格写成已验证论文贡献。
